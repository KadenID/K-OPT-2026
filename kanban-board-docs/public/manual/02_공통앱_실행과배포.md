# 실행과 배포

## 내려받아 실행하기

사용하는 컴퓨터에 맞는 릴리즈 파일을 내려받아 압축을 해제합니다.

| 컴퓨터          | 릴리즈 대상             | 실행 파일              |
| ------------ | ------------------ | ------------------ |
| Windows 64비트 | `win-x64` ZIP      | `Kopt2026.App.exe` |
| M 시리즈 Mac    | `osx-arm64` TAR.GZ | `K-OPT 2026.app`   |
| Intel Mac    | `osx-x64` TAR.GZ   | `K-OPT 2026.app`   |

별도의 .NET 설치는 필요하지 않습니다. 파일 → 열기로 모델을 불러오거나 직접 입력한 뒤 **실행**을 누릅니다. 자세한 사용법은 [간단 사용 설명서](01_K-OPT_2026_간단사용설명서_0.2.md)를 참고하세요.

실행 단축키는 Windows에서 `F5` 또는 `Ctrl+Enter`, Mac에서 `(Fn+)F5` 또는 `⌘+Enter`입니다. Mac의 `Fn` 사용 여부는 키보드의 기능 키 설정에 따라 달라집니다.

Mac용은 교차 빌드한 미리보기입니다. 한글 입력기·파일 선택 창 등 실제 Mac 환경의 추가 검증이 필요하며, 공개 배포용 Apple 서명·공증은 완료되지 않았습니다.

## 소스에서 실행하기

.NET 10 SDK를 설치한 뒤 저장소 루트에서 실행합니다.

```sh
dotnet run --project kanban-board/src/Kopt2026.App
```

## 릴리즈 만들기

.NET 10 SDK와 PowerShell 7.4 이상이 필요합니다. 저장소 루트에서 원하는 대상의 명령을 실행합니다.

```powershell
# Windows
pwsh -File kanban-board/tools/Publish-Release.ps1 -RuntimeIdentifier win-x64
# M 시리즈 Mac
pwsh -File kanban-board/tools/Publish-Release.ps1 -RuntimeIdentifier osx-arm64
# Intel Mac
pwsh -File kanban-board/tools/Publish-Release.ps1 -RuntimeIdentifier osx-x64
```

결과는 `kanban-board/dist/releases`에 저장됩니다. 릴리즈 파일은 Git 추적에서 제외되며, 사용설명서(`manual`), 예제(`samples`)와 이용 조건·라이선스 고지(`legal`)가 함께 포함됩니다. 실제 실행 확인 여부는 배포본의 `validation.json`에 기록됩니다.
