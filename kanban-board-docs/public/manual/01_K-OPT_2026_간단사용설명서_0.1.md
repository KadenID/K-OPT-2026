# K-OPT 2026 간단 사용 설명서

문서 버전: 0.1  
대상: K-OPT 2026 일반 사용자

## 1. 프로그램 시작

1. `Kopt2026.App.exe`를 실행합니다.
2. 새 모델을 작성하려면 **파일 → 새 문서**를 선택합니다.
3. 작성된 `.opt` 파일을 사용하려면 **파일 → 열기**를 선택합니다.

프로그램을 실행하면 왼쪽의 **모델 편집기**에 모델을 입력할 수 있습니다.

## 2. 모델 입력 기본 구조

모델은 다음 순서로 입력합니다. 각 부분은 줄을 나누어 작성합니다.

```text
MAX 또는 MIN
목적식
ST
제약식 1
제약식 2
...
END
```

- `MAX`: 목적값을 최대화합니다.
- `MIN`: 목적값을 최소화합니다.
- `ST`: 제약식 입력의 시작을 나타냅니다.
- `END`: 모델 입력의 끝을 나타냅니다.

모든 변수는 기본적으로 **0 이상인 연속변수**로 처리됩니다. (비음 제약식을 작성하지 않아도 됩니다.)

## 3. 기본 입력 규칙

| 항목 | 입력 방법 | 예시 |
|---|---|---|
| 변수명 | 영문자로 시작하고 숫자와 `_`를 사용할 수 있습니다. | `X1`, `PRODUCT_A` |
| 변수 항 | 계수와 변수명을 함께 씁니다. 공백은 생략할 수 있습니다. | `3 X1`, `3X1` |
| 목적식 | 변수 항을 `+` 또는 `-`로 연결합니다. 상수항도 사용할 수 있습니다. | `3 X1 + 2 X2 + 10` |
| 제약식 | 한 줄에 하나씩 입력합니다. | `2 X1 + X2 <= 10` |
| 관계기호 | `<=`, `>=`, `=` 중 하나를 사용합니다. | `X1 + X2 >= 5` |
| 제약식 이름 | 필요하면 제약식 앞에 `이름:`을 붙입니다. | `CAPACITY: 2 X1 + X2 <= 10` |
| 정수변수 | 제약식 다음에 `INTEGER`로 선언합니다. | `INTEGER X1, X2` |
| 주석 | `#`으로 시작하는 줄은 계산에서 제외됩니다. | `# 생산계획 예제` |

곱셈기호 `*`는 입력하지 않습니다. 예를 들어 `3*X1` 대신 `3 X1` 또는 `3X1`을 사용합니다.

## 4. 선형계획 입력 예제

다음 예제는 `3X1 + 2X2`를 최대화하는 모델입니다.

```text
MAX
3 X1 + 2 X2
ST
CAPACITY: 2 X1 + X2 <= 10
DEMAND: X1 + 3 X2 <= 12
END
```

제약식 이름인 `CAPACITY`와 `DEMAND`는 생략할 수 있습니다. 이름을 생략하면 프로그램이 자동으로 C1, C2 등의 이름을 붙입니다.

## 5. 정수계획 입력 예제

변수가 정수값만 가져야 한다면 `END` 앞에 `INTEGER` 줄을 추가합니다.

```text
MAX
5 X1 + 3 X2
ST
RESOURCE: 2 X1 + X2 <= 7
MIX: X1 + 2 X2 <= 8
INTEGER X1, X2
END
```

`INTEGER`에 적는 변수는 목적식이나 제약식에 먼저 사용되어 있어야 합니다.

## 6. 사용 순서

1. **모델 입력**  
   왼쪽 모델 편집기에 모델을 입력하거나 `.opt` 파일을 엽니다.

2. **문서 검증**  
   상단의 **검증** 버튼을 누릅니다. 입력 오류가 있으면 아래 **진단** 탭에서 오류가 발생한 행과 수정 방법을 확인합니다. 단축키는 `Ctrl+Shift+B`입니다.

3. **최적화 실행**  
   상단의 **▶ 실행** 버튼을 누르거나 `F5`를 누릅니다.

4. **결과 확인**  
   오른쪽에서 목적값을 확인하고, 아래 탭에서 필요한 결과를 확인합니다.

   - **변수 해**: 각 변수의 최적값
   - **제약식**: 좌변 계산값, 우변, 여유·잉여, 쌍대값
   - **그래프**: 2변수 모델의 실행가능영역과 최적점
   - **민감도 분석**: 목적식 계수와 제약식 우변의 허용 범위
   - **복수 최적해**: 복수 최적해 여부와 확인된 대표해
   - **원본 K-OPT 형식 출력**: K-OPT 형식으로 정리된 결과

   표의 열 제목에 마우스를 올리면 해당 항목의 설명을 볼 수 있습니다.

5. **저장 또는 내보내기**  
   모델은 **파일 → 저장**으로 저장합니다. 계산 결과를 별도 파일로 저장하려면 **파일 → 결과 내보내기**를 사용합니다.

## 7. 입력 오류가 발생할 때

- `MAX` 또는 `MIN`, 목적식, `ST`를 각각 별도 줄에 입력했는지 확인합니다.
- 관계기호는 `≤`, `≥` 문자가 아니라 키보드로 `<=`, `>=`를 입력합니다.
- 제약식 우변에는 숫자만 두고 변수 항은 관계기호 왼쪽으로 옮깁니다.
- 변수 항 사이에 `+` 또는 `-`가 빠지지 않았는지 확인합니다.
- 모델 마지막에 `END`가 있는지 확인합니다.

오류가 계속되면 **진단** 탭의 `메시지`와 `수정 힌트`를 먼저 확인합니다.

## 8. 구형 K-OPT 파일 열기

구형 K-OPT 파일도 **파일 → 열기**로 불러올 수 있습니다. 프로그램이 변환 가능한 구형 형식을 발견하면 K-OPT 2026 형식으로 바꾸어 편집기에 표시합니다. 원본 파일은 변경하지 않으며, 저장할 때 새 파일명으로 저장합니다.
