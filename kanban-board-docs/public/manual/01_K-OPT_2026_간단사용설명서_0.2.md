# K-OPT 2026 간단 사용 설명서

문서 버전: 0.2  
수정일: 2026-11-09  
대상: K-OPT 2026 0.3.4-preview의 Windows·Mac 사용자

## 1. 프로그램 시작

1. Windows에서는 `Kopt2026.App.exe`, Mac에서는 `K-OPT 2026.app`을 실행합니다.
2. 새 모델을 작성하려면 **파일 → 새 문서**를 선택합니다.
3. 작성된 `.opt` 파일은 **파일 → 열기**로 불러옵니다. 배포본의 `samples` 폴더에도 예제가 있습니다.

왼쪽 **모델 편집기**에 수식을 입력합니다. 상단 도구 모음은 **새 문서·열기·저장·검증·실행·중지**로 구성됩니다.

## 2. 모델 입력 기본 구조

모델은 다음 순서로 입력합니다. `MAX` 또는 `MIN`, `ST`, `END`는 각각 별도 줄에 입력합니다.

```text
MAX 또는 MIN
목적식
ST
제약식 1
제약식 2
...
END
```

- `MAX`: 목적값을 최대화합니다.
- `MIN`: 목적값을 최소화합니다.
- `ST`: 제약식 입력의 시작입니다.
- `END`: 모델 입력의 끝입니다.

모든 변수는 기본적으로 **0 이상인 연속변수**입니다. 정수변수는 `INTEGER`로 지정합니다.

## 3. 기본 입력 규칙

| 항목 | 입력 방법 | 예시 |
|---|---|---|
| 변수명 | 영문자로 시작하며 이후 영문자·숫자·`_`를 사용할 수 있습니다. 대소문자는 구분하지 않습니다. | `X1`, `PRODUCT_A` |
| 변수 항 | 계수와 변수명을 함께 씁니다. 공백은 생략할 수 있습니다. | `3 X1`, `3X1` |
| 목적식 | 변수 항을 하나 이상 포함하고 `+`·`-`로 연결합니다. 상수항과 여러 줄 입력을 지원합니다. | `3 X1 + 2 X2 + 10` |
| 제약식 | 한 줄에 하나씩 쓰며 양변에 변수와 상수를 사용할 수 있습니다. | `2 X1 + 5 <= X2 + 10` |
| 관계기호 | `<=`, `>=`, `=` 중 하나를 사용합니다. | `X1 + X2 >= 5` |
| 제약식 이름 | 필요하면 제약식 앞에 `이름:`을 붙입니다. | `CAPACITY: 2 X1 + X2 <= 10` |
| 정수변수 | 제약식 다음, `END` 앞에 선언합니다. | `INTEGER X1, X2` |
| 주석 | `#`으로 시작하는 줄은 계산에서 제외됩니다. | `# 생산계획 예제` |

제약식 `2 X1 + 5 <= X2 + 10`은 내부에서 `2 X1 - X2 <= 5`로 정리됩니다. 결과 표·그래프·민감도 분석은 정리된 식을 기준으로 표시하며, 편집기의 수식은 바꾸지 않습니다. 우변에만 사용한 변수도 기본적으로 0 이상인 결정변수입니다.

목적식을 여러 줄로 나눌 때도 항 사이의 `+`·`-`를 유지합니다. 예를 들어 `3 X1 +` 다음 줄에 `2 X2 + 10`을 이어 쓸 수 있습니다. 제약식은 여러 줄로 나누지 않습니다.

곱셈기호 `*`는 입력하지 않습니다. `3*X1` 대신 `3 X1` 또는 `3X1`을 사용합니다. 변수끼리의 곱셈·나눗셈이나 거듭제곱은 지원하지 않습니다.

## 4. 선형계획 입력 예제

다음 모델의 최적 목적값은 `16.4`입니다.

```text
MAX
3 X1 + 2 X2
ST
CAPACITY: 2 X1 + X2 <= 10
DEMAND: X1 + 3 X2 <= 12
END
```

제약식 이름을 생략하면 C1, C2 등의 이름이 자동으로 붙습니다. 아래처럼 우변에 변수 항을 두어도 같은 모델로 계산합니다.

```text
MAX
3 X1 + 2 X2
ST
2 X1 <= 10 - X2
3 X2 <= 12 - X1
END
```

## 5. 정수계획 입력 예제

변수가 정수값만 가져야 한다면 `END` 앞에 `INTEGER` 줄을 추가합니다. 다음 모델의 최적 목적값은 `19`입니다.

```text
MAX
5 X1 + 3 X2
ST
RESOURCE: 2 X1 + X2 <= 7
MIX: X1 + 2 X2 <= 8
INTEGER X1, X2
END
```

`INTEGER`에 적는 변수는 목적식이나 제약식에서 사용한 변수여야 합니다. 제약식 우변에만 사용한 변수도 지정할 수 있습니다.

## 6. 사용 순서와 단축키

1. **입력**: 모델을 작성하거나 `.opt` 파일을 엽니다.
2. **검증**: 상단의 **검증**을 누릅니다. 오류가 있으면 **진단** 탭에서 행·열, 메시지와 수정 힌트를 확인합니다.
3. **실행**: 상단의 **실행**을 누릅니다. 저장하지 않은 현재 편집본도 계산할 수 있습니다. 실행 중에는 **중지**로 취소를 요청할 수 있습니다.
4. **결과 확인**: 오른쪽 목적값과 아래 결과 탭을 확인합니다.
5. **저장·내보내기**: 모델은 **파일 → 저장**, 계산 결과는 **파일 → 결과 내보내기**로 저장합니다. 내보내기는 TXT·CSV·JSON을 지원합니다.

| 작업 | Windows | Mac |
|---|---|---|
| 새 문서 | `Ctrl+N` | `⌘+N` |
| 열기 | `Ctrl+O` | `⌘+O` |
| 저장 | `Ctrl+S` | `⌘+S` |
| 다른 이름으로 저장 | `Ctrl+Shift+S` | `⌘+Shift+S` |
| 검증 | `Ctrl+Shift+B` | `⌘+Shift+B` |
| 실행 | `F5` 또는 `Ctrl+Enter` | `(Fn+)F5` 또는 `⌘+Enter` |
| 실행 취소 | `Shift+F5` | `Shift+(Fn+)F5` |

Mac의 `(Fn+)F5` 표기는 키보드 설정에 따라 `Fn+F5`가 필요하다는 뜻입니다. 표준 기능 키 모드에서는 `F5`만 누릅니다. 실행 취소도 같은 조건으로 `Fn`을 함께 누릅니다.

모델을 수정하면 기존 계산 결과는 지워집니다. 수정한 모델의 결과를 확인하거나 내보내려면 다시 실행합니다.

## 7. 결과와 화면 조절

- **진단**: 입력 문법 오류·경고와 수정 힌트
- **변수 해**: 변수별 최적값·변수 유형·수정비용
- **제약식**: 정리된 식의 좌변 계산값·우변·여유/잉여·쌍대값
- **민감도 분석**: 최적성이 확인된 연속형 LP의 목적계수·우변 허용 범위. 다른 항목은 고정하고 한 항목만 바꿀 때의 범위이며, 정수모형에서는 지원하지 않습니다.
- **그래프**: 2변수 모델의 실행가능영역·최적점. 그 외 변수 수에서는 변수값을 막대그래프로 표시합니다.
- **복수 최적해**: 최적성이 확인된 결과의 유일성 판정·변수별 최적 범위·대표해. 분석이 제한 시간 안에 끝나지 않으면 확인된 범위만 표시합니다.
- **로그**: 계산 상태·솔버·계산 시간 등

위쪽 **원본 K-OPT 형식 출력**은 계산 결과를 K-OPT 표 형식으로 재구성한 호환 보기입니다. 표의 열 제목에 마우스를 올리면 항목 설명을 볼 수 있습니다.

영역 사이 경계를 드래그해 너비·높이를 조절할 수 있으며, 각 영역에는 최소 크기가 있습니다. 내용이 넘칠 때만 스크롤바가 나타납니다. 긴 표는 가로 스크롤로 확인하고, 문서 끝까지 내려 마지막 행을 확인할 수 있습니다. 스크롤바는 영역 경계에 배치되며 본문과 겹치지 않습니다.

**설정** 메뉴에서는 결과 표의 한글 항목 표시, 그래프의 X·Y절편 표시, 소수 자릿수를 조절합니다. 소수 자릿수는 **0~15자리**, 기본값은 **6자리**이며 화면 표시만 반올림합니다. 계산 정밀도는 바꾸지 않으며 내보낸 파일의 숫자 표시는 화면과 다를 수 있습니다. 설정은 다음 실행에도 유지됩니다.

## 8. 파일 저장과 구형 파일 열기

UTF-8·CP949 파일을 열 수 있으며, 저장은 UTF-8로 합니다. 모델을 바꾸거나 프로그램을 종료할 때 저장하지 않은 내용이 있으면 저장 여부를 묻습니다.

구형 K-OPT 파일도 **파일 → 열기**로 불러옵니다. 자동 변환한 내용이 현재 문법으로 검증되면 변환본을 편집기에 표시합니다. 열기만으로 원본 파일을 바꾸지는 않습니다. 변환본을 처음 저장할 때 저장 위치 선택 창이 열리므로, **원본을 보존하려면 다른 파일명으로 저장**합니다.

## 9. 입력 오류가 발생할 때

- `MAX` 또는 `MIN`, `ST`, `END`를 각각 별도 줄에 입력했는지 확인합니다.
- 목적식에 변수 항이 하나 이상 있는지 확인합니다.
- 관계기호는 `≤`·`≥` 대신 `<=`·`>=`를 입력합니다.
- 제약식은 한 줄에 쓰고 관계기호를 하나만 사용합니다. 양변 모두 변수·상수를 사용할 수 있습니다.
- 항 사이에 `+`·`-`가 빠지지 않았는지 확인합니다. 여러 줄 목적식도 같은 규칙을 따릅니다.
- 변수끼리 곱하거나 나누는 비선형식을 사용하지 않았는지 확인합니다.
- 모델 마지막에 `END`가 있는지 확인합니다.

오류가 계속되면 **진단** 탭의 `메시지`와 `수정 힌트`를 확인합니다.
