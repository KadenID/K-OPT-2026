# K-OPT 2026

Windows용 교육용 선형·정수 최적화 데스크톱 프로그램입니다. `.opt` 파일을 UTF-8/CP949로 열고, 문법 진단 후 HiGHS로 LP/MIP를 계산합니다. 2변수 모델은 실행가능영역과 최적점을 그래프로 확인할 수 있습니다.

## 개발 실행

```powershell
dotnet restore Kopt2026.slnx
dotnet build Kopt2026.slnx -c Release
dotnet run --project src/Kopt2026.App/Kopt2026.App.csproj
```

## 주요 단축키

- F5: 실행
- Shift+F5: 취소
- Ctrl+Shift+B: 검증
- Ctrl+O / Ctrl+S: 열기 / 저장

## 그래프와 결과 용어

- 결과를 실행한 뒤 하단 `그래프` 탭에서 실행가능영역, 제약 경계, 목적함수, 최적점을 확인합니다.
- 2변수 그래프는 각 제약식과 목적식의 X절편·Y절편을 축 표식과 오른쪽 요약 목록으로 보여줍니다.
- 가까운 절편 좌표 라벨은 실제 글자 크기에 따라 자동으로 자리를 옮기며 서로 겹치지 않습니다. 이동한 라벨은 같은 색 연결선으로 원래 절편과 이어집니다.
- 화면 공간이 부족해 축 라벨을 배치할 수 없는 경우에도 오른쪽 `X·Y절편` 목록에서 전체 값을 확인할 수 있습니다.
- `설정 → 그래프에 X·Y절편 표시`에서 절편 표식과 요약 목록을 켜거나 끌 수 있습니다. 끄면 그래프가 오른쪽 영역까지 넓어집니다.
- 최적해가 확인되면 목적값 카드에서 `고유 최적해` 또는 `복수 최적해` 여부를 바로 알립니다.
- `복수 최적해` 탭에서 각 변수의 최적 범위와 최대 10개의 대표 최적해를 확인할 수 있습니다. 대표해 목록은 전체 열거가 아닙니다.
- 범위 분석이 기본 10초 안에 끝나지 않으면 고유해로 단정하지 않고 `복수 최적해 판정 미완료`로 표시합니다.
- 변수가 3개 이상이면 변수 최적값 막대그래프가 표시됩니다.
- `설정 → 결과 표 항목을 한글로 표시`에서 `Slack`, `Dual`, `Reduced Cost` 등의 표기를 한국어/영어로 전환할 수 있습니다.
- 용어 및 절편 표시 설정은 다음 실행에도 유지됩니다.
- 목적값, 변수·제약 결과와 그래프 숫자는 `2,053,333,333.33`처럼 천 단위 구분기호로 표시됩니다. 불필요한 소수부 0은 붙이지 않습니다.

새 문서는 UTF-8(BOM 없음)로 원자적 저장합니다. 레거시 CP949 문서는 자동 감지하여 열되 원본을 자동 덮어쓰지 않습니다.
